# ✦ Outliers Collective — Team Portfolio & Engineering Showcase

> **“We Don’t Fit the Box. We Build Outside It.”**  
> *Official Hackathon Candidacy Dossier & Engineering Showcase — Smart India Hackathon (SIH) Champions.*

An award-winning, interactive 3D portfolio engineered with Next.js, Three.js, WebGL, and modern liquid champagne gold aesthetics.

---

## ✦ Core Features

- **Photorealistic 3D Moon**: Persistent Three.js lunar surface with physical craters, ACESFilmic tone mapping, and continuous Y-axis axial rotation with zero scroll blur.
- **Interactive OUTLIERS Letter Synthesizer**: Web Audio API sine harmonic chime player on letter click with squad codenames and constellation combos.
- **Dynamic Cosmic Sky Background**: 60fps drifting starfield canvas, randomized streaking meteors (*"tutate tare"*), and floating zero-G sleeper astronaut.
- **Auto-Scroll 1-by-1 Ghibli Card Flip**: Sticky sequential reveal transitioning from professional portrait cards to Ghibli alter-egos as the user traverses the team section.
- **Student Profile Dossiers**: Deep modal views with concise 1–2 line summaries for About, Flagship Projects, Verified Achievements, and full-resolution Evidence Screenshot Lightbox.
- **Universal Team Projects**: High-impact problem statements, solutions, performance metrics, and verified repositories.
- **Miniature Spaceship Cursor**: Flight vector tracking with real-time billowing golden thruster gas fog particles.
- **Cosmic Scroll Progress**: Slim celestial vertical trajectory tracking page depth without rendering premature future tracks.

---

## ✦ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **3D & Graphics**: [Three.js](https://threejs.org/), WebGL, HTML5 Canvas, Web Audio API
- **Styling**: Vanilla CSS Design Tokens, Liquid Champagne Gold Glassmorphism (`globals.css`)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Testing**: [Vitest](https://vitest.dev/) & [Testing Library](https://testing-library.com/)

## ✦ Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/PURVAMARVE/Outliers.git
cd Outliers

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## ✦ Production Build & Testing

```bash
# Run unit tests
npm test

# Type-check TypeScript
npx tsc --noEmit

# Create optimized production build
npm run build

# Start production server
npm start
```

## ✦ One-Click Deployment (Vercel)

Deploy this project instantly to [Vercel](https://vercel.com/):

1. Import this repository into Vercel.
2. Framework Preset: **Next.js**
3. Build Command: `next build`
4. Output Directory: `.next`
5. Click **Deploy**!
